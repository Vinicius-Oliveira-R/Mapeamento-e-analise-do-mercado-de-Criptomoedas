# Sistema Inteligente de Mapeamento e Análise do Mercado de Criptomoedas
Este repositório é dedicado a matéria de machine learning, cujo o objetivo é fazer uma analise de uma criptomoeda e prever seu valor.

## Objetivo
Para realizar a análise de criptomoedas vamos criar um algoritmo Web Scraping para acessar um site (que ainda será escolhido), retirar as informações e arquiva-las em um arquivo JSON ou CSV para gerar nosso próprio DATASET.

## Tecnologias utilizadas:
Selenium/requests-html

Python 

Machine Learning
